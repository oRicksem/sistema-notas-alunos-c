# Sistema de Gerenciamento de Notas de Alunos
Projeto em C para a disciplina de Laboratório de Programação Estruturada

descrição:
Sistema completo para gerenciamento de notas de alunos com persistência em arquivo binário.

Funcionalidades:
-  Cadastro de alunos (nome, matrícula, nota)
-  Consulta de alunos por posição
-  Persistência de dados em arquivo binário
-  Interface de menu interativa
-  Leitura segura de strings

Tecnologias:
- Linguagem C
- Arquivos binários
- Estruturas (struct)
- Manipulação de arquivos

Compilação e Execução:
```bash
gcc gerenciador_alunos.c -o gerenciador_alunos
./gerenciador_alunos
